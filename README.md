Zbiór autorskich scenariuszy do gry fabularnej Zew Cthulhu, stworzonej przez Chaosium Inc. >>> https://www.chaosium.com/
W niektórych scenariuszach znajdują się odniesienia do podręczników opublikowanych przez Chaosium, wydanych w Polsce nakładem Black Monk Games >>> https://blackmonk.pl/

Wszystkie prawa zastrzeżone przez ich autorów. Żadne treści niniejszych podręczników nie są publikowane w scenariuszach Arkham Elders.

Wszystkie opublikowane historie dostępne są całkowicie za darmo i takie pozostaną. Można je do woli przerabiać i wykorzystywać do prowadzenia własnych, nieodpłatnych sesji. Jakiekolwiek czerpanie korzyści majątkowych z publikacji lub powielania jest całkowicie zabronione.
